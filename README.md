# 훈노트 (Hoon Note)

태블릿 **가로 화면**에 최적화된 안드로이드 강의 판서 + 화면 녹화 앱입니다.
아이캔노트(iCanNote)처럼 **넓은 노트 위에 PDF를 얹고, 오른쪽 여백에 판서**하는 구조로 2.0에서 화면을 개편했고,
3.0에서 태블릿 실사용 피드백 10가지를 반영했고(종료 확인, PDF 페이지 범위·회전, 상태바 숨김, 필압,
굵기 단계 확장, 형광펜 색/굵기, 지우개 2종), 3.1에서 녹화를 전체화면 한 가지로 단순화하고
1페이지짜리 PDF가 흰 화면으로 나오던 버그를 고쳤습니다.
3.2에서는 녹화 화질(용량) 프리셋 `일반(고화질)` / `절약(720p 저용량)` 을 넣어, 선오공 Q&A 답변 영상처럼
가볍게 올릴 녹화를 몇 MB대로 찍을 수 있게 했습니다.
3.3에서는 **PDF·이미지를 지우지 않고 뒤에 이어서 쌓고**, 페이지 배경을 캐시 파일로 돌려 수십 장을 쌓아도
램을 많이 쓰지 않게 했습니다(`새 노트` 버튼으로 한 번에 비우기).
3.4에서는 **삼각형·점선 직선·흰 덮개 떡메모지·글자** 도구를 더하고, 화면 이동/줌 도구를 없애 두 손가락
터치로만 옮기게 했으며, 포스트잇도 캔버스에 사각형을 그려 그 자리에 놓게 바꿨습니다.
판서 → 페이지 넘김 → PNG/PDF 저장 → MP4 화면녹화까지 한 화면에서 처리합니다.

- Kotlin / Android Views (Compose 미사용)
- minSdk 26 (Android 8.0) · targetSdk 34 · compileSdk 34
- AGP 8.5.2 · Kotlin 1.9.24 · Gradle 8.9

## 빌드 (GitHub Actions)

`.github/workflows/build-apk.yml` 이 푸시할 때마다 디버그 APK를 만듭니다.
`gradle-wrapper.jar` 없이 `gradle/actions/setup-gradle@v4` 로 Gradle 8.9 를 받아 `gradle assembleDebug` 를 실행합니다.

> **참고:** 이 워크플로 파일은 GitHub 앱(Pickle)의 `workflows` 권한이 없어 저장소에 아직 올라가 있지 않습니다.
> GitHub Settings → Applications → Pickle 에서 **Workflows 권한**을 켠 뒤 푸시하거나, GitHub 웹에서
> `Actions → New workflow` 로 같은 내용을 붙여넣으면 됩니다. 소스 자체는 로컬에서 빌드 검증을 마쳤습니다.

1. GitHub 에 `hoonmathaca/hoonnote` 저장소를 만든다.
2. 이 폴더를 그대로 푸시한다.
3. Actions 탭 → `Build Debug APK` → 실행 결과의 **Artifacts** 에서 `app-debug-apk` 다운로드.
4. APK 를 태블릿에 설치(출처를 알 수 없는 앱 설치 허용 필요).

로컬 빌드도 동일합니다:

```bash
# JDK 17 + Android SDK(platform 34, build-tools 34.0.0) 필요
gradle assembleDebug
# 결과: app/build/outputs/apk/debug/app-debug.apk
```

## 3.4 변경 사항 (삼각형 · 점선 직선 · 덮개 떡메모지 · 글자 · 포스트잇 사각형)

1. **삼각형 도구** — 사각형·원과 똑같이 드래그로 크기를 정합니다. 그린 사각형에 꼭 맞는 삼각형(위 꼭대기, 아래 양 모서리)이 지금 고른 색·굵기로 그려지고, 선 지우개·부분 지우개로 통째로 지워집니다.
2. **점선 직선** — 기존 화살표(반직선) 버튼 자리에 **점선 직선**을 넣었습니다. 사선으로 그은 선의 굵기에 맞춰 점선 간격이 정해지고, PDF 위에 점선으로 보조선을 그을 때 씁니다. (직선·사각형·원 같은 실선 도형은 그대로 있습니다.)
3. **이동/줌 도구 제거** — 툴바에서 `이동/줌` 버튼을 없앴습니다. 화면 이동·확대는 **손가락 두 개**(핀치·팬, 0.5x~10x)로만 하고, 한 손가락은 지금처럼 필기입니다. `화면/배경 → 화면 맞춤` 도 같은 자리에 있습니다.
4. **덮개 떡메모지(흰 사각형)** — `덮개` 도구로 사각형을 그리면 그 자리를 **불투명 흰색**으로 덮어 해설·그림을 가립니다. 덮은 위에 펜·형광펜·도형으로 새로 쓸 수 있습니다.
   - 덮개는 그린 순서대로 겹쳐지므로, 덮개를 친 뒤에 쓴 필기는 위에 보이고 덮기 전에 쓴 필기는 가려집니다.
   - 지우개로 덮개 **안쪽**을 문질러도 덮개는 지워지지 않습니다(그 위 필기만 지워짐). 덮개를 없애려면 **테두리를 문지르거나** `실행취소`를 씁니다. 부분 지우개로도 덮개는 조각나지 않습니다.
5. **글자 도구** — `글자`를 고르고 캔버스를 누르면 입력 팝업이 뜨고, 넣은 글자는 **배경·테두리 없이** 지금 펜 색과 글자 크기로 그 자리에 그려집니다. 굵기 칩이 글자 크기 단계(26·36·50·68·90·120)로 바뀌어 크기를 고를 수 있고, 실행취소·다시실행과 페이지 전환에도 요소로 남습니다.
6. **포스트잇은 그려서 놓기** — `포스트잇` 도구를 고르면 "캔버스에 사각형을 그리면 그 자리에 포스트잇이 생깁니다" 안내가 뜨고, 드래그하는 동안 점선 사각형 미리보기가 보입니다. 손을 떼면 그 위치·크기로 포스트잇이 생기고, 탭만 하면 누른 자리에 기본 크기(340×280)로, 너무 얇게 그리면 최소 크기(140×110)로 놓입니다. 놓은 뒤에는 지금처럼 끌어서 옮기고 ×로 지웁니다.

## 3.3 변경 사항 (PDF 이어 쌓기 · 메모리 절약 · 새 노트)

1. **PDF·이미지를 이어서 쌓기** — PDF나 이미지를 새로 열면 기존 페이지와 필기를 지우고 처음부터 시작하는 대신, **지금 노트 뒤에 새 페이지가 이어 붙습니다**. 붙인 뒤에는 방금 붙은 첫 새 페이지로 저절로 이동합니다. 수업 자료를 단원별로, 문제집을 단계별로 이어 붙여 한 노트에 모을 수 있습니다.
   - 아직 아무것도 없는 빈 노트 한 장뿐일 때만 그 빈 장을 지우고 새 PDF로 시작합니다(빈 장이 남지 않음).
   - 앞 페이지의 필기·포스트잇·형광펜은 그대로 남습니다.
2. **메모리 절약(배경 캐시)** — PDF·이미지 배경은 앱 내부 캐시 폴더(`cacheDir/page-backgrounds`)에 파일로 두고, **지금 보는 페이지와 앞뒤 한 장만** 메모리에 올립니다(LRU, 48MB 예산). 페이지를 옮기면 캐시에서 바로 읽고, 앞뒤 페이지는 미리 파일로 만들어 두어 넘길 때 기다리지 않습니다. 회전하면 그 페이지만 다시 그리고, 페이지를 삭제하면 그 배경 캐시도 함께 지웁니다.
3. **새 노트(전체 비우기)** — 상단 `새 노트` 버튼(또는 `강의 → 새 노트`)을 누르면 확인 팝업 뒤에 페이지·필기·불러온 PDF·임시 캐시를 모두 지우고 빈 한 장으로 돌아갑니다. 수업이 바뀔 때 씁니다.
4. **저장·내보내기는 그대로** — 페이지 PNG 저장과 전체 PDF 내보내기도 캐시 파일에서 배경을 읽어 메모리에 페이지 수만큼 비트맵을 들고 있지 않습니다.

## 3.2 변경 사항 (녹화 화질·용량 설정)

1. **녹화 화질(용량) 프리셋** — 설정 → 화면 녹화 맨 위에서 `일반 (고화질)` / `절약 (720p 저용량 · 강의 공유용)` 중 하나를 고르면 해상도·프레임·비트레이트가 한 번에 정해지고, 바로 아래에 1분당 예상 용량이 표시됩니다.

   | 프리셋 | 해상도 | 프레임 | 비트레이트 | 1분 예상 용량 | 선오공 Q&A(50MB)에 |
   | --- | --- | --- | --- | --- | --- |
   | 일반 (고화질) | 1080p | 30fps | 12Mbps | 약 89MB | 약 30초 |
   | 절약 (720p 저용량) | 720p | 24fps | 1.5Mbps | 약 12MB | 약 4분 |

   (예상 용량 = 영상 비트레이트 + 소리 128kbps, 마이크를 끄면 조금 더 작습니다. 실제 MP4 는 헤더·가변 비트레이트 때문에 조금 다를 수 있습니다.)
2. **기본값은 절약** — 새로 설치하거나 설정을 초기화하면 `절약(720p · 24fps · 1.5Mbps)` 으로 시작합니다. 선오공 Q&A 답변 영상(최대 50MB)에 4분까지 들어가는 크기입니다. 3.1 에서 직접 골라 둔 해상도·프레임·비트레이트는 그대로 이어받습니다(예: 12Mbps → 12000kbps).
3. **녹화 메뉴에서 바로 바꾸기** — 상단 `녹화` 메뉴에 `화질: 절약 (720p 저용량)` 처럼 지금 화질이 보이고, 누르면 용량이 적힌 두 가지 중에서 고를 수 있습니다. 녹화 버튼은 3.1 처럼 팝업 없이 곧바로 시작하며, 바꾼 화질은 다음 녹화부터 적용됩니다.
4. **세부 설정 유지** — 해상도·프레임·비트레이트를 직접 고르면 프리셋 선택이 풀리고 `직접 설정` 으로 용량만 안내합니다(비트레이트 선택지에 1.5Mbps 추가).

## 3.1 변경 사항 (3.0 실기기 테스트 피드백)

1. **녹화는 전체화면 한 가지만** — 녹화 버튼을 누르면 `페이지만/전체화면` 선택 팝업 없이 곧바로 전체화면 녹화가 시작되고, 다시 누르면 멈춥니다. '페이지만' 크롭 녹화(GL + MediaCodec 경로)는 오류가 잦아 코드째 제거했습니다.
2. **1페이지짜리 PDF 흰 화면 버그 수정** — 페이지 범위는 1부터 세지만 `PdfRenderer`는 0부터 세는데, 그 변환이 빠져 1페이지 PDF는 모든 페이지가 범위 밖이 되어 아무것도 그려지지 않았습니다. `PdfPages.toIndices()` 한 곳에서 변환하고, 1페이지 PDF가 실제 픽셀로 그려지는지 검증하는 테스트를 추가했습니다.
3. **PDF를 노트 안쪽에 자동 배치(fit-inside)** — 페이지마다 실제 비율로 노트 안쪽 영역을 계산해 여백 2%만 남기고 최대한 크게, 비율 유지한 채 넣습니다(90/180/270° 회전도 동일). 배경은 노트 픽셀의 1.75배 해상도로 그려 확대해도 선명하고, 아주 큰 페이지는 픽셀 예산(5M) 안으로 줄여 메모리 부족으로 흰 화면이 되지 않게 했습니다.

## 3.0 변경 사항 (실사용 피드백 10가지)

1. **종료 확인** — 시스템 뒤로가기·상단 `강의 → 종료` 모두 `종료할까요?` 팝업을 거칩니다. 녹화 중이면 “녹화를 끝내고 앱을 닫습니다” 안내가 함께 나옵니다.
2. **PDF 열기 전 페이지 설정** — 파일을 고르면 곧바로 열지 않고 `총 N페이지`를 보여준 뒤 열 범위(`1-5`, `3`, `1-`, `9-10, 12`, `전체`)를 입력받습니다.
3. **PDF 회전** — 열기 다이얼로그에서 0°/90°/180°/270°를 고르거나, 상단 `화면/배경 → PDF 회전`으로 문서 전체를 90° 단위로 돌립니다. 가로로 누운 스캔 PDF 대응.
4. **녹화해도 화면이 바뀌지 않음** — 녹화 버튼을 눌러도 전체화면·툴바 숨김이 강제로 적용되지 않습니다(자동 숨김은 설정에서 직접 켤 때만).
5. ~~녹화 영역 선택~~ — 3.1에서 제거했습니다(전체화면 녹화만 유지).
6. **상태바·내비바 숨김** — `WindowCompat.setDecorFitsSystemWindows(false)` + `WindowInsetsControllerCompat.hide(systemBars())`(스와이프로만 잠깐 표시)를 `onCreate`·`onResume`·`onWindowFocusChanged` 에서 다시 적용합니다.
7. **필압** — 설정에서 필압 감지 ON/OFF. 켜면 스타일러스 압력(`MotionEvent.getPressure()` ÷ 기기 최대 압력)에 따라 선 굵기가 35%~100% 로 자연스럽게 변합니다(압력 미지원 기기·손가락은 굵기 일정).
8. **굵기 단계 확장** — 세필 1.5 부터 3·5·8·13·22 까지 6단계(형광펜은 8~52), 설정 슬라이더로 0.5~48 사이 세밀 조절.
9. **형광펜** — 노랑·연두·분홍·하늘·주황·보라 전용 팔레트와 굵기 단계를 따로 기억합니다(반투명 알파 적용).
10. **지우개 2종** — `선 지우개`(닿은 획 전체 삭제)와 `부분 지우개`(문지른 구간만 잘라내고 남은 조각을 새 획으로 분리). 툴바에서 한 번에 전환합니다.

## 2.0 화면 구조 (아이캔노트형 3영역)

```
┌────────────────────────────────────────────────────────────┐
│ 상단 메뉴 바  강의 · 저장 · 페이지 · 화면/배경 · 녹화 · 설정  │
├──────┬─────────────────────────────────────┬───────────────┤
│ 썸네일│        노트 캔버스 (넓은 흰 노트)     │  세로 판서 툴바│
│  1   │  ┌──────────┐                       │  ● 녹화        │
│  2   │  │ PDF 페이지│   ← 풀이 여백 →      │  펜 형광       │
│  3   │  └──────────┘                       │  직선 화살     │
│  …   │                                     │  사각 원       │
│2/13  │                                     │  메모 지우개   │
│ + 🗑 │                                     │  이동 취소/재실│
│      │                                     │  굵기·색 팔레트│
│      │                                     │  ◀ 2 ▶        │
└──────┴─────────────────────────────────────┴───────────────┘
```

- **노트 캔버스 위에 PDF/이미지**: PDF를 화면 전체에 늘리지 않고, 노트(기본 2560×1440 와이드) 높이의 96%에
  맞춰 좌측 정렬로 얹습니다. 오른쪽(또는 양옆)에는 수학 풀이용 흰 여백이 남고, 옅은 점선 안내선이 그려집니다.
- **판서는 노트 전체에**: PDF 위든 오른쪽 여백이든 자유롭게 그려지고, PNG/PDF 내보내기에도 여백·PDF·판서가
  통째로 저장됩니다.
- **좌측 썸네일 바**: 페이지 번호 + 실시간/캐시 썸네일, 하단 `n / N Page` · `+`(추가) · `🗑`(삭제).
  상단 바의 레이어 아이콘으로 접고 펼칩니다.
- **우측 세로 툴바**: 오른손 S펜 조작용 2열 아이콘. 맨 위 `● 녹화`(녹화 중 경과 시간/중지), 도구 접기,
  펜·형광펜·직선·점선 직선·사각형·원·삼각형·덮개·글자·포스트잇·지우개·Undo·Redo, 굵기 빠른 선택,
  8색 원탭 팔레트, 맨 아래 `◀ n ▶` 페이지 이동.
- **바 숨김**: 상단 바의 아이콘으로 좌측/우측 바를 각각 접거나 모두 숨길 수 있고, 숨겼을 때는
  좌상단의 작은 `도구` 버튼으로 복귀합니다. 전체화면(Immersive) 토글도 유지됩니다.

## 기능

### 화면 / 노트
- 가로 화면 고정 (`sensorLandscape`)
- 전체화면(Immersive) 토글 — 상태바/내비바 숨김, 스와이프로 일시 표시
- 노트 크기 선택(설정): 와이드 16:9 2560×1440 · FHD 1920×1080 · 4:3 2048×1536 · A4 가로 2970×2100
- PDF/이미지 정렬: **좌측 정렬(오른쪽 풀이 여백)** / 가운데 정렬, 노트 여백 0~12% 조절
- 배경: 화이트 / 크림 / 칠판 녹색 / 다크 네이비 / 모눈

### 강의 · 페이지
- 새 강의, PDF 열기(`PdfRenderer`), 이미지 열기(PNG/JPG, 최대 2400px)
- 페이지 추가(현재 페이지 뒤), 페이지 삭제, 이전/다음 페이지, 썸네일 탭으로 바로 이동
- 두 손가락 핀치 줌 + 팬 (0.5x~10x, 3.4 부터 이동/줌 도구 없이 터치만), `화면 맞춤`

### 판서 도구
- 펜(8색 원탭 팔레트, 필압), 형광펜(전용 6색·굵기, 반투명), 지우개 2종(획 전체 / 부분)
- 도형: 직선, 점선 직선, 사각형, 원(타원), 삼각형 — 드래그로 크기 조절
- 덮개 떡메모지: 불투명 흰 사각형으로 해설을 덮고 그 위에 새로 판서(테두리를 문지르면 지워짐)
- 글자: 캔버스를 눌러 입력, 배경 없이 펜 색·글자 크기로 표시
- 실행취소/다시실행 (페이지별 60단계)
- 포스트잇: 캔버스에 사각형을 그려 그 자리에 추가, 끌어서 이동, 메모 입력, × 로 삭제
- 팜리젝션: 스타일러스 우선 인식. 설정에서 **펜 전용 / 손가락 허용** 전환
  (기본값은 폰 테스트용 **손가락 허용**. 태블릿 수업에서는 **펜 전용** 권장)

### 저장
- 현재 페이지 **PNG** → `Pictures/HunsuNote` (노트 여백 + PDF + 판서 전체)
- 전체 페이지 **PDF** → `Download/HunsuNote` (`PdfDocument`, 노트 비율 유지)
- Android 10+ 는 MediaStore(스코프 저장소) 사용, Android 9 이하는 공용 폴더 + 미디어 스캔

### 화면 녹화 (MP4)
- **전체화면 녹화 한 가지**: 녹화 버튼 → 곧바로 시작(선택 팝업 없음), 다시 누르면 종료
- `MediaProjection` + 포그라운드 서비스(`mediaProjection` 타입)
- 마이크 음성 함께 녹음(설정에서 ON/OFF)
- 설정: **화질 프리셋** `일반(고화질)` 1080p·30fps·12Mbps / `절약(720p 저용량)` 720p·24fps·1.5Mbps,
  세부 설정으로 해상도 720p/1080p, 프레임 24/30fps, 비트레이트 1.5/4/8/12Mbps 직접 선택
- 녹화 메뉴에서 화질(용량)을 바꾸면 다음 녹화부터 적용(녹화 중이면 지금 영상은 그대로)
- Android 14 규칙 준수: **포그라운드 서비스 시작 → getMediaProjection → 가상 디스플레이** 순서
- 저장: `Movies/HunsuNote`, 알림의 **중지** 버튼으로 종료

## 알려진 한계 (프로토타입)

- 판서 데이터는 앱을 끄면 사라집니다(파일 저장/불러오기 없음). 결과물은 PNG/PDF/MP4 로 남깁니다.
- 부분 지우개는 자유 곡선(펜·형광펜)만 잘라냅니다. 직선·점선·사각형·원·삼각형·글자·덮개는 형태를 유지해야 해서 닿으면 통째로 지워집니다(덮개는 테두리 가까이를 문지를 때만).
- 노트 크기 변경은 **새 강의·새 페이지**부터 적용됩니다(이미 그린 판서 좌표가 어긋나지 않게 하기 위함).
  정렬/여백은 열려 있는 강의에도 바로 적용됩니다.
- 썸네일은 200px 폭으로 다시 그린 캐시입니다(판서 후 약 0.5초 뒤 갱신).
- 녹화는 화면 전체를 담습니다(앱 화면만 잘라 담는 기능 없음).
